# Affiliate Telegram Bot

Python Telegram bot for Amazon India and Flipkart affiliate link conversion.

## Features

- Amazon/Flipkart URL detection
- Affiliate link conversion
- Short link generation
- Product title, price, rating and image fetching
- Telegram channel auto-posting
- Admin panel
- Analytics dashboard
- Inline buttons
- Optional AI product description

## Setup

1. Create Telegram bot from BotFather.
2. Copy bot token.
3. Add bot as admin in your Telegram channel.
4. Create `.env` file using `.env.example`.

## Local Run

```bash
pip install -r requirements.txt
python bot.py
